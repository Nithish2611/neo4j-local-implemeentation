Cognitive Code Graph

Turn a codebase into a queryable knowledge graph and ask it questions in plain English. Python, JavaScript and PHP are parsed with tree-sitter into Neo4j, and a local LLM answers using the exact code and call relationships it retrieves. Nothing leaves your machine.

What it does

Graph-native retrieval

Instead of similar-looking text chunks, the model gets the functions you name plus what calls them and what they call, so answers follow the real execution path.

Multi-language parsing

Exact node rules per language for Python, JavaScript (including arrow functions and methods) and PHP. Vendor folders and minified bundles are skipped.

Chat UI with verified edits

A Streamlit chat streams answers and proposes changes as diffs. Nothing is written until you apply it, and edits that would break syntax or touch stale files are refused.

Self-healing memory

Applying an edit re-ingests just that file and rebuilds its cross-file call links, so the graph never drifts from the code.

Use it in your own project

pip install "git+https://github.com/Nithish2611/neo4j-local-implemeentation.git"

cognitive-graph --path . --question "How does login work?"
cognitive-graph --skip-ingest --question "What calls save_user?"

You need Python 3.10+, a running Neo4j 5.x, and either Ollama (for example qwen2.5-coder:7b) or a Gemini API key. Connection details go in a .env file. The README has the details.

Why there is no live demo

The assistant reads your source code and can edit files, so it is designed to run on your own machine next to your own Neo4j and model. A public instance would have to ship your code to a server, which defeats the point. Clone the repo to try it.
